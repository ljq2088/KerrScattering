The two Kerr/CFT factorization files separate the exact fixed-incident
normalization identity into the linear horizon intensity and the residual
unit-horizon nonlinear Green kernel.  Their fitted slopes are finite-window
diagnostics; in particular, the supplementary rows are not interpreted as
critical exponents derived from the conformal weight.

The paired `power_band` files sample the common throat-frequency window
`-0.5 <= p/kappa <= 1.2` for the `n=2,3` principal modes.  The bandwidth
summary integrates those monochromatic susceptibilities and tests the
predicted `kappa^(1-n)` hierarchy.  The paired `power_peakdense` files add
`n=1` on a `Delta(p/kappa)=0.05` grid at `a/M=0.9999`; the peak-migration
summary records five-point local log-quadratic peak locations and widths.

Most exploratory CSV files are intentionally ignored by git.  The files above
are unignored because they are direct inputs to
`docs/prd/kerr_scalar_nonlinear_GF_baseframe.tex`.  The older lower-order
axisymmetric sweeps remain as an audit trail; the active PRD figures combine
the `hires` and `dense` files at $N=240$ and quadrature order $q=192$ with
the high-frequency tail files.  All 43 points in the three tail-fit windows
are recomputed at $N=240$ and $q=2048$ after the tracked quadrature-order
audit.

The spectral residual CSV contains 600 Chebyshev--Gauss validation points for
each of the `down`, `up`, and `in` homogeneous branches.  These 1800 points are
off the Lobatto collocation grid used in the solve; the stored derivatives are
obtained analytically from the phase-peeled Chebyshev interpolants.

`kerr_scalar_angular_convergence.csv` compares the active spheroidal truncation
and angular quadrature with a 24-extra-mode, 512-point reference for both the
largest displayed axisymmetric spheroidal parameter and the displayed
`l=m=2` to `l'=6` target channel.

`kerr_scalar_axisymmetric_low_frequency_convergence.csv` audits the lowest
displayed point for each axisymmetric multipole with sequential variations of
the Chebyshev order, Green-integral quadrature order, and matching radius.  It
records process RSS so the bounded-memory execution can be checked directly.
The displayed endpoints are selected by
`abs(T1 + R1) <= 1e-8`; completed rows below those endpoints remain only in the
raw sweep files and are not used by manuscript plots or physical fits.

The superradiant response files compare equilibrated endpoint solves at
`(N,q)=(288,320)` and `(320,384)`.  The accepted file contains only points with
a relative change in `horizon_response=T1/T0` no larger than `1e-5`, together
with independent linear-flux and Wronskian gates.  Reflected-channel balance is
recorded separately because direct `R1` cancellation can fail even when the
horizon response is spectrally converged.  The displayed windows are contiguous
around the threshold and are truncated before low-frequency or high-frequency
relative accuracy is lost.

The near-extremal files use the natural variables
`y=(omega-m*Omega_H)/kappa` and `Xi=M*kappa*horizon_response`.  The `N144` and
`N176` pairs are the manuscript inputs; lower-order and pilot files remain an
untracked audit trail.  Exact zero detuning is deliberately omitted because the
horizon Frobenius roots coalesce there.  Threshold values are selected from
symmetric nonzero detunings, while the radial collocation grid still includes
the event horizon.

The modal power-law audit uses seven modes on
`a=0.98,0.99,0.995,0.997,0.999`, with selected channels extended to
`a=0.9995,0.9999`.  The threshold label `y=0` is derived from
`y=+/-0.025,+/-0.05` by even symmetrization and Richardson extrapolation.
The fixed-`y` fits use only `y=-0.5,0.5,1` raw rows.  Fits are repeated over
all, nearest-four, and nearest-three accepted spins; the output also records
the extremal conformal weight and a pure-power versus finite-limit AICc
comparison.  Rows that fail the paired-resolution gate remain in the raw CSVs
but are excluded from all fits and figures.

The scalar-monopole files use the same runner with `m=0`, for which
`y=omega/kappa` and no finite-frequency superradiant threshold exists.  The
summary contains quadratic zero-frequency extrapolations for eight spins and
their comparison with the analytic response `log(2)/pi`.  At `a=0.999`, the
summary deliberately uses the stable `y=0.05,0.1,0.2` window; the two smaller
frequencies are retained in the raw files as conditioning diagnostics but are
not used in the manuscript result.

The axisymmetric-infrared pair evaluates the deeper horizon-side limit for
`l=0,1,2` at simultaneous `(N,q)=(144,144)` and `(176,176)`.  It records the
analytic Bessel integral, the matched static/far-zone coefficients of
`T0` and `T1`, and their finite-frequency deviations.  The infinity-side
`R1` balance is retained only as a conditioning diagnostic at these very low
frequencies; the manuscript infrared conclusion uses the independently
converged horizon response and Wronskian.  The companion infrared-fit table
contains seven-, six-, and five-point free log--log fits used to audit
convergence toward the analytic powers `2l+2`.

The power-nonlinearity files test the analytic scalar-monopole hierarchy for
`|Phi|^(2n) Phi` with `n=2,3`.  The fixed-frequency pair covers seven
frequencies and five spins; the fixed-`omega/kappa` pair tests the predicted
near-extremal powers on five high spins.  The summary files pair the two
resolutions, fit the infrared powers, extrapolate the analytic coefficients,
and record fit-window, linear-balance, Wronskian, and memory diagnostics.  The
spectral-quality triplet is an independent homogeneous audit at
`(a,omega,N)=(0.5,0.0005,176)`; the same homogeneous mode is used for every
nonlinearity order.

The power near-extremal files extend the nonaxisymmetric modal experiment to
`|Phi|^(2n) Phi` with `n=2,3`.  Threshold values use the four nonzero offsets
`y=+/-0.025,+/-0.05`; fixed-path rows use `y=0.5`, with `y=-0.5,1` also
available for `(1,1)` and `(2,2)`.  The base `N=144/176` pair covers five
spins and the extreme `N=224/256` pair covers `a=0.9995,0.9998,0.9999`.
The two principal channels are extended through
`a=0.99995,0.999975,0.9999875,0.99999375` with `N=256/288` and through
`a=0.999996875,0.9999984375` with `N=288/320`.  The primary principal fit
therefore contains seven points on `0.9999 <= a <= 0.9999984375`.
Rejected `(2,1)` extreme rows remain in the raw files but are excluded by the
paired-response gate.  The fit file records free exponents, 95% slope
intervals, logarithmic residuals, and leave-one-out errors.  The data support
an order-locked principal envelope with modest finite-window modulation, not
an exact pure power; supplementary rows remain crossover diagnostics.  The
angular-convergence file compares the active 16-extra-mode,
256-point projection with a 24-extra-mode, 512-point reference.
