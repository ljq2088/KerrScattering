# PRD 审阅与收束记录

日期：2026-10-07。对象：英文研究论文，不是中文全工作笔记。原 `kerr_scalar_nonlinear_GF_baseframe.tex`、既有数值与中文笔记未覆盖。新稿是 `kerr_scalar_nonlinear_prd_review_20261007.tex`。

## 首要发现

1. **阻断非轴对称数值结论的端点不一致。** `src/kerr_scalar_spectral.py:170` 仍使用 `B0(0)=-radial_lambda`。对论文给定的外区剥相位函数，独立符号展开得到 `B0(0)=-lambda-2*a*m*omega`。因此原稿摘要第 50–68 行中的近极端包络、算符阶次锁定及其衍生结论，需要修正端点后重算。共同收敛、Wronskian 和守恒检查不能排除此类系统误差。新稿只采用不受此差异影响的 `m=0` 径向结果；原非轴对称历史数据没有删除，也没有假装完成重算。

2. **基础稿的引用与约定需要明确。** 读取本地 `nonlinear_GF.pdf` 的标题页及第 II–III 节，确认题名为 *Nonlinear scattering problem in black hole spacetimes*，作者为 Zhen-Tao He、Yu Tian、Hongbao Zhang，版本日期为 2026-06-15。检索未核实该版本的公开发表记录。新稿按所提供稿件引用，不编造 DOI 或期刊。原稿的势幂次索引 `N` 与本稿 `n` 满足 `N=n+1`，方程级耦合满足 `epsilon_n=-lambda_ref`。原参考的一阶系数采用单位视界解，不能未经入射归一化转换与本稿相比。共振峰、指数尾并不是本稿首次发现的现象。

3. **极限和精度需要分层。** 固定次极端自旋的 `omega -> 0` 匹配结果，不能直接当作自旋趋于极端时的统一定理。高阶单极最低频局部残差最大值约为 `1.6e-5`；响应的两分辨率稳定性和极高拟合 R² 不等价于全域机器精度。现有离网残差主要检验齐次场，不是重构非齐次一阶场的独立局部残差。

4. **原稿过度分散。** 原摘要同时负载低频、阈值、principal/supplementary、阶次锁定、带宽和峰迁移。部分叙述重复，EMRI 背景的比重高于其与本问题的直接关系。新稿让标题、摘要和结论围绕固定入射能流及可核验的红外层级展开。

5. **尾部采点的正文计数不一致。** 原方法段仍写 25 个高阶求积采点，而结果段和尾模型表给出 19、14、10 个点，合计 43。新稿将方法段改成三个尾拟合窗口共 43 点；没有更改表格或数据。

## 新稿结构

标题：*Weakly nonlinear scalar scattering on Kerr: flux response and infrared hierarchy*。

- 引言明确与所提供 Schwarzschild 稿、非线性引力散射、束缚云和自力理论的区别；不声称泛化已知峰和尾就是独立新物理。
- 问题定义保留一般 Kerr、`s=0` 的几何、作用量、角源投影和边界能流。
- 方法保留端点包含两域 Chebyshev、Green 函数、相对残差和守恒检验；补上外区精确端点公式，并区分无穷远不规则奇点与端点兼容关系。
- 结果先给出轴对称低频匹配与全 `n` 单极层级，再给有限频率曲线和非旋转极限。数值表的单元格不改写。
- 讨论区分解析恒等式、固定自旋渐近、已记录数值及未计算的物理；不由线性 Kerr/CFT 推断非线性幂律。
- 附录保留详细能流及 Schwarzschild 归一化推导，并增加原基础稿的幂次、耦合符号转换。

## 可支持的核心结论

| 陈述 | 证据 | 限定 |
|---|---|---|
| 一阶能流来自零阶与一阶场的干涉；`T1+R1=0` | 当前解析推导与边界归一化 | 固定背景、实耦合、复标量 U(1) 相互作用 |
| 三次轴对称 `T0,T1 ~ (M omega)^(2 ell+2)` | 静态 Legendre 与波区 Bessel 匹配、已有双分辨率结果 | 每个固定次极端自旋；不证明双极限统一性 |
| 单极相对响应趋于 `ln(2)/pi`，复幅度响应还有相位部分 | 可求值 Green 积分 | 不是未经归一化的视界系数 |
| 全 n 单极 `chi_n ~ c_n omega^(2n-2)`，`c_n>0` | 分部积分与有限对数求和 | 对此固定入射红外观测量的层级，不是 RG 定理 |
| n=2、3 的系数与幂次得到支持 | 原 CSV、两分辨率、窗口变化 | 本轮没有新扫描 |
| 峰位靠近 QNM 频率尺度；尾在有限窗口偏好指数拟合 | 原曲线、窗口测试、AICc/LOO | 不识别 QNM 极点/残量，不证明热谱 |
